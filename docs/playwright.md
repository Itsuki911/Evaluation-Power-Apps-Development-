# ブラウザー確認と Playwright

## 方針

既存の Codex の Chrome/Computer Use と既存 Playwright MCP があるため、新しいブラウザー MCP は追加しません。
今回 Chrome のタブ取得 API に `timeoutMs` エラーが出ましたが、ネイティブ Chrome の画面取得で Studio の描画を確認できました。再発時も新しい MCP の追加より既存機能の復旧を優先します。

公式 Power Platform Playwright samples の iframe の分離、アプリ固有の描画完了条件、認証状態の再利用を参考に、小さな独立テストを用意しました。公式 toolkit 全体は導入していません。
公式の Northwind サンプルはソリューション導入とデータ操作を伴うため、そのまま実行しません。パスワード環境変数の例も採用せず、対話サインインを使用します。

## 検証用設定

```sh
mkdir -p .local
chmod 700 .local
cp config/app.example.json .local/app.json
```

| 設定 | 値の決め方 |
|---|---|
| `testOnly` | 検証用アプリであることを人が確認したら `true` |
| `startupReviewed` | App.OnStart、Screen.OnVisible、Timer 等が実データを変更しないと確認したら `true` |
| `playUrl` | アプリの詳細画面の再生リンクをコピー。Studio URL や推測した tenantId は使わない |
| `frameSelectors` | 実画面で確認した iframe の CSS セレクターを外側から順に指定。トップ文書なら `[]` |
| `readyText` | 初期画面内で一意な表示文字列。ログイン画面やシェルだけにある文字は使わない |
| `readOnlyAction` | 初回は `null`。未設定では操作テストがスキップされる |

公式サンプルには `iframe[name="fullscreen-app-host"]` がありますが、実環境で確認するまで設定しません。iframe が入れ子なら複数指定できます。
空のアプリには固有の readyText がない場合があります。アプリ作成・編集の依頼後に検証用の表示を用意するまで、実アプリテストは未準備です。

非更新の画面遷移ボタンなどを確認できたら、次の形で設定します。名前は実画面から取得してください。

```json
{
  "confirmedNonMutating": true,
  "buttonName": "実際のボタンのアクセシブル名",
  "expectedText": "操作後に表示される一意の文字列"
}
```

## 実行

```sh
npm run auth
npm test -- --project=desktop --headed
npm test
```

`auth` が開いたブラウザーで人がサインイン・MFA を完了し、ターミナルで Enter を押します。
画面内の readyText が確認できた場合だけ `.local/auth.json` に状態を保存します（モード 600）。パスワードは保存しません。
認証状態は秘密情報です。期限切れなら `npm run auth` を再実行します。sessionStorage を必要とする認証や組織の条件付きアクセスでは再利用できない場合があり、未検証です。MFA や組織ポリシーは迂回しません。

テストは画面幅 1440×900 と 390×844 で表示を確認します。見た目の妥当性、重なり、文字切れは人／Codex の画面確認も必要です。表示文字列の検査だけでレスポンシブ品質が合格とはしません。

## 結果と機密

スクリーンショット・動画・trace は既定で無効です。失敗時のエラー文や Playwright が残す補助ファイルにも画面情報が含まれ得るため、結果は `.local/` に出力します。端末ログの共有にも注意します。
手動で画像を撮る場合も `.local/` に保存し、PR に添付する前に内容を確認してください。`git add -f` で除外を回避しないでください。

## 将来追加するテスト

- 画面遷移と戻る操作：前後の表示と選択状態を確認。
- 検索：検証用データに対するヒット・ゼロ件を確認。
- 入力：必須・形式の検査。自動保存がないことを先に確認。
- 保存・再表示：明示的に許可された検証専用データで、テスト識別子と後片付けを設計してから追加。
- 複数幅：文字切れ・スクロール・押せる領域を画面でも確認。

上記は今回実行していません。ブラウザーのインストール成功、ローカル HTML の成功、Power Apps の成功を区別してください。
